THE IDEA

A return journey.
Not just a locked door.

At a festival, a wallet or a set of keys can easily become someone else’s lost-and-found problem. This course prototype explores a simple handover: staff register the item, the locker stores an owner record, and a matching personal card releases the latch.

05 / A PROTOTYPE, NOT A PROMISE

What works.
What comes next.

The prototype demonstrates the card-to-latch interaction. A real unattended locker would need more than this proof of concept.

01 / OWNERSHIP

Assign the right person.

The saved sketch assigns new items to a hardcoded owner. Next: a staff flow that pairs each found item with its actual owner.

02 / MEMORY

Keep the records.

Ten records live in RAM. Next: capacity checks and persistent storage, so a power cycle does not erase the inventory.

03 / PHYSICAL STATE

Know what happened.

The original uses an eight-second latch window, without door or item sensors. Next: detect closure and collection before confirming a return.

04 / INTERACTION

Make the workflow complete.

Descriptions are entered through Serial Monitor and delays block the loop. Next: a staff interface, non-blocking timing and a stronger enclosure.

The interactive model is a teaching illustration, not measured CAD. Its guided safeguards are browser additions, not features claimed for the original hardware. The original sketch remains unchanged.
