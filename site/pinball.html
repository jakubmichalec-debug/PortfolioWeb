Pinball machine

A playable table with solenoid flippers, scoring targets and a ball-loading system, all run from one Arduino sketch. Everything below is real - scroll through how it was actually built, and click any model, photo or clip to open it full-screen.

CAD, code and wiring: Jakub Michalec  ·  Team: Nina Hajdikova, Grigor Grigorov

  • FreeCAD
  • PrusaSlicer
  • Arduino
  • Laser cutter
  • HC-SR04
  • RFID

How a game starts: tap an RFID card on the reader, like an access card, and the score resets and a new game begins. The code excerpts below come from an earlier version of the sketch, from before the reader went in.
